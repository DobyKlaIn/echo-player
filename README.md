# Эхо — музыкальный плеер для iPhone

Личный бесплатный плеер, который собирает лучшее из Яндекс Музыки, Spotify и VK Музыки.

## Скачать

Последняя версия всегда здесь:
**https://github.com/DobyKlaIn/echo-player/releases/latest/download/Echo.ipa**

Файл не подписан — подпиши его своим сертификатом (ESign, Scarlet, GBox, Feather и т.п.) и установи.

## Что умеет

**Из Яндекс Музыки**
- «Моя волна» — бесконечный поток из твоей музыки с характером: Микс, Любимое, Незнакомое, Популярное, Свежее
- Лайк и «Не рекомендовать»: волна учится на лайках, дизлайках и пропусках

**Из Spotify**
- Плавный переход между треками (кроссфейд до 12 секунд)
- Синхронные тексты песен с прокруткой (бесплатная база LRCLIB, или свой .lrc рядом с треком)
- Очередь: «играть следующим», «в конец очереди», перетаскивание
- Подборки: Любимые, Часто слушаю, Давно не слушал, Недавно добавленные
- «Мои итоги»: минуты прослушивания, топ треков и исполнителей

**Из VK Музыки**
- Своя музыка без подписки и без интернета: mp3, m4a, flac, wav
- Добавление прямо из Telegram: «Поделиться» → «Эхо»
- Плейлисты, исполнители, альбомы, поиск

**Онлайн (Audius)**
- Бесплатная музыка независимых артистов: поиск, тренды по жанрам, популярные плейлисты
- Онлайн-треки играют сразу, а потом переключаются на движок с эквалайзером и плавными переходами
- Лайки, плейлисты вместе со своей музыкой, «Открытия из Audius» в «Моей волне»

**Сверху**
- 10-полосный эквалайзер с пресетами
- Интернет-радио: тысячи станций, жанры, избранное
- Таймер сна, AirPlay, управление с экрана блокировки и наушников
- Цвет оформления: как в Яндексе, Spotify, VK или свой

## Как добавить музыку

- **Telegram:** нажми на трек → «Поделиться» → «Эхо»
- **Файлы:** «Файлы» → «На iPhone» → «Эхо» → «Музыка», перетащи треки или папки
- **В приложении:** «Медиатека» → «+» → «Добавить файлы» или «Добавить папку»

## Сборка

Каждый push в `main` собирает `.ipa` в GitHub Actions (XcodeGen + Xcode) и публикует его в Releases.
